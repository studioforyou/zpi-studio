## Definition of Done

A task is considered **done** only when all of the following conditions are met:

1. **Requirements fulfilled** – all requirements and acceptance criteria described in the task are implemented.
2. **Code review** – the changes were submitted via a Pull Request and received at least one approving review.
3. **Merged to `main`** – the Pull Request has been merged into the `main` branch.
4. **Pipeline passes** – the CI pipeline runs successfully (build, linting, tests).
5. **Nothing is broken** – the changes do not introduce regressions; existing functionality keeps working.
6. **Conventions followed** – the code, branch, commits and PR follow the rules described in [NAMING_CONVENTIONS.md] (NAMING_CONVENTIONS.md) and [WORKFLOW.md] (WORKFLOW.md).
